# Módulo 6 - Tipos Primitivos e Operadores 🔣

Este diretório contém os exercícios do **Módulo 6** do curso de Java Backend da EBAC. O foco está em praticar o uso de **tipos primitivos**, **operadores aritméticos**, **relacionais** e **lógicos**, além de entender como manipular variáveis e expressões.

## Objetivo

- Declarar e inicializar variáveis com tipos primitivos (`int`, `double`, `char`, `boolean`, etc.).
- Utilizar operadores para realizar cálculos e comparações.
- Compreender precedência de operadores e expressões compostas.

## Estrutura

- `Operadores.java`: Classe principal que demonstra o uso de operadores em diferentes contextos.
- Exemplos de operações matemáticas, comparações e lógica booleana.
