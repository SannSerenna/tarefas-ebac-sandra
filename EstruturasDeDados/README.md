# Estruturas de Dados 🧠

Este diretório contém exercícios práticos sobre **estruturas de dados em Java**, desenvolvidos como parte do curso de Java Backend da EBAC. O objetivo é aplicar conceitos fundamentais como listas, pilhas, filas e árvores, reforçando a lógica e a organização de dados.

## Conteúdo

- `ListaEncadeada.java`: Implementação de uma lista encadeada com métodos de inserção, remoção e busca.
- `Pilha.java`: Estrutura de pilha com operações de empilhar e desempilhar.
- `Fila.java`: Estrutura de fila com inserção e remoção em ordem.
- Outros arquivos podem incluir testes ou exemplos de uso.

## Conceitos Praticados

- Estruturas lineares e dinâmicas.
- Manipulação de nós e ponteiros.
- Recursão e iteração.
- Encapsulamento e reutilização de código.
