# Recursividade em Java 🔁

Este diretório contém exercícios práticos sobre **recursividade**, desenvolvidos como parte do curso de Java Backend da EBAC. O objetivo é aplicar e entender como funções recursivas funcionam, resolvendo problemas de forma elegante e eficiente.

## Objetivo

- Implementar algoritmos que utilizam chamadas recursivas.
- Resolver problemas clássicos como fatorial, Fibonacci e somatórios.
- Compreender o fluxo de execução e a pilha de chamadas.

## Conteúdo

- `Recursividade.java`: Classe principal com métodos recursivos.
  - Cálculo de fatorial
  - Sequência de Fibonacci
  - Soma de números
  - Impressão de caracteres recursiva
