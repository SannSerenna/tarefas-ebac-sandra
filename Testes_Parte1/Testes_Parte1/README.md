# Testes - Parte 1 🧪

Este diretório contém os primeiros exercícios relacionados a **testes automatizados em Java**, desenvolvidos como parte do curso de Java Backend da EBAC. O foco está em aplicar os conceitos de **Test Driven Development (TDD)** e utilizar ferramentas como **JUnit** para validar o comportamento do código.

## Objetivo

- Criar testes unitários para classes Java.
- Validar funcionalidades com diferentes cenários.
- Aplicar boas práticas de escrita de testes.

## Estrutura

- `Cliente.java`: Classe que representa a entidade cliente.
- `IClienteDAO.java`: Interface para operações de acesso a dados.
- `ClienteDAO.java`: Implementação da interface com lógica de persistência.
- `ClienteDAOTest.java`: Classe de testes unitários utilizando JUnit.

## Tecnologias Utilizadas

- Java 17+
- JUnit 5
- Maven (se aplicável)
