# Módulo 19 - Reflection em Java 🔍

Este diretório contém uma aplicação Java que demonstra o uso da **API de Reflection**, desenvolvida como parte do Módulo 19 do curso de Java Backend da EBAC. O objetivo é explorar como inspecionar e manipular classes, métodos e atributos em tempo de execução.

## Objetivo

- Utilizar a API de Reflection para acessar informações de classes.
- Invocar métodos e acessar atributos dinamicamente.
- Compreender os riscos e benefícios do uso de Reflection.

## Estrutura

- `MinhaClasse.java`: Classe de exemplo com atributos e métodos.
- `App.java`: Classe principal que utiliza Reflection para inspecionar e interagir com `MinhaClasse`.

## Funcionalidades Demonstradas

- Obtenção de nome da classe e seus métodos.
- Acesso a atributos privados.
- Invocação de métodos via `Method.invoke()`.
- Listagem de construtores e modificadores.
