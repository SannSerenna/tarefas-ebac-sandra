# EBAC Services 🛠️

Este diretório contém uma implementação de serviços Java como parte das atividades do curso de Java Backend da EBAC. O projeto tem como objetivo aplicar conceitos de orientação a objetos, modularização e reutilização de código.

## Funcionalidades

- Criação de serviços com métodos específicos.
- Demonstração de encapsulamento e separação de responsabilidades.
- Simulação de chamadas de serviço em uma aplicação simples.

## Estrutura

- `Servico.java`: Classe que representa um serviço genérico com métodos reutilizáveis.
- `Main.java`: Classe principal que executa os serviços e exibe os resultados.
