# Calculadora Projeto - EBAC

Este diretório contém a implementação de uma **calculadora simples em Java**, desenvolvida como parte das atividades do curso de Java Backend da EBAC.

## Funcionalidades

A calculadora permite realizar operações básicas como:

- Adição
- Subtração
- Multiplicação
- Divisão

## Estrutura

- `Calculadora.java`: Classe principal que contém os métodos para cada operação matemática.
- `Main.java`: Ponto de entrada da aplicação, responsável por interagir com o usuário e chamar os métodos da calculadora.
