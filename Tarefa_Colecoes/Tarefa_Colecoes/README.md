# Tarefa - Coleções em Java 📦

Este diretório contém uma aplicação Java desenvolvida como parte das atividades do curso de Java Backend da EBAC. O foco está em praticar o uso de **coleções** como `List`, `Set` e `Map`, além de aplicar conceitos de ordenação e manipulação de dados.

## Objetivo

- Criar uma estrutura de cadastro de produtos.
- Armazenar os produtos em uma coleção.
- Exibir os produtos ordenados por nome ou preço.
- Demonstrar o uso de `Comparator` e `Comparable`.

## Estrutura

- `Produto.java`: Classe que representa um produto com atributos como nome, código e preço.
- `CadastroProduto.java`: Classe que gerencia a coleção de produtos e implementa funcionalidades como ordenação e exibição.
- `Main.java`: Classe principal que executa o sistema e demonstra o uso das coleções.
