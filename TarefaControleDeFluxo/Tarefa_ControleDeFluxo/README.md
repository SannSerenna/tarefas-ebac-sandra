# Tarefa - Controle de Fluxo 🔄

Este diretório contém uma aplicação Java simples que utiliza **estrutura condicional** para avaliar o desempenho de um aluno com base em suas notas. O projeto foi desenvolvido como parte das atividades do curso de Java Backend da EBAC.

## Objetivo

- Solicitar o nome do aluno e quatro notas.
- Calcular a média aritmética.
- Exibir o resultado com base na média:
  - Aprovado (média ≥ 7)
  - Recuperação (média ≥ 5 e < 7)
  - Reprovado (média < 5)

## Estrutura

- `Tarefa_ControleDeFluxo.java`: Classe principal que realiza a leitura dos dados, cálculo da média e exibição do resultado com base em estruturas condicionais (`if`, `else`).
