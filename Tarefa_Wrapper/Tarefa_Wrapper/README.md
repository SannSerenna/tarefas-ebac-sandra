# Tarefa - Wrapper Classes 🔢

Este diretório contém uma aplicação Java que demonstra o uso das **Wrapper Classes**, desenvolvida como parte das atividades do curso de Java Backend da EBAC. O objetivo é entender como os tipos primitivos podem ser encapsulados em objetos e utilizados em contextos mais flexíveis.

## Objetivo

- Utilizar classes wrapper como `Integer`, `Double`, `Boolean`, entre outras.
- Demonstrar conversões entre tipos primitivos e objetos.
- Aplicar métodos úteis das classes wrapper.

## Estrutura

- `Tarefa_Wrapper.java`: Classe principal que realiza operações com diferentes tipos de wrappers, como conversão de valores, comparação e uso de métodos específicos.
