# Primeiro Exemplo com Spring Boot 🌱

Este diretório contém uma aplicação Java desenvolvida como parte do **Módulo 40** do curso de Java Backend da EBAC. O projeto tem como objetivo apresentar os primeiros passos com o **Spring Boot**, criando uma API REST simples.

## Funcionalidades

- Exposição de endpoints REST com `@RestController`
- Retorno de mensagens via HTTP
- Estrutura básica de projeto Spring Boot

## Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Maven
- Postman ou navegador para testes

## Estrutura

- `controller/`: Contém a classe que define os endpoints da API.
- `application.properties`: Arquivo de configuração da aplicação.
- `PrimeiroExemploSpringBootApplication.java`: Classe principal que inicia o projeto.
