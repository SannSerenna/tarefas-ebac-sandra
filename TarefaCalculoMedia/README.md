# Tarefa - Cálculo de Média 📊

Este diretório contém uma aplicação Java simples para **calcular a média de notas**, desenvolvida como parte das atividades do curso de Java Backend da EBAC.

## Objetivo

- Solicitar ao usuário quatro notas.
- Calcular a média aritmética.
- Exibir o resultado e indicar se o aluno foi aprovado ou reprovado.

## Estrutura

- `Media.java`: Classe principal que realiza a leitura das notas, cálculo da média e exibição do resultado.
