# Generics em Java 🧬

Este diretório contém uma implementação prática do conceito de **Generics** em Java, desenvolvida como parte das atividades do curso de Java Backend da EBAC. O objetivo é demonstrar como criar classes e métodos genéricos que funcionam com diferentes tipos de dados.

## Objetivo

- Aplicar o conceito de **tipagem genérica** para aumentar a reutilização de código.
- Criar estruturas flexíveis que funcionem com múltiplos tipos sem perder segurança de tipo.

## Conteúdo

- `Generica.java`: Classe genérica que pode armazenar e manipular qualquer tipo de dado.
- Exemplos de uso com diferentes tipos (ex: `String`, `Integer`, `Double`).
