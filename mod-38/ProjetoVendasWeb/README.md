# Projeto Vendas Web - Módulo 38 🌐

Este diretório contém uma aplicação web desenvolvida como parte do **Módulo 38** do curso de Java Backend da EBAC. O projeto simula um sistema de vendas com interface web, utilizando **Spring Boot** e **Thymeleaf**.

## Funcionalidades

- Cadastro de produtos com nome, código e preço.
- Registro de vendas com cálculo de valor total.
- Interface web para interação com o sistema.
- Exibição de listas de produtos e vendas.

## Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Spring MVC
- Thymeleaf
- Maven
- HTML/CSS

## Estrutura

- `controller/`: Classes responsáveis por lidar com requisições HTTP.
- `model/`: Classes que representam entidades como `Produto` e `Venda`.
- `repository/`: Interfaces para persistência de dados (simulada ou real).
- `templates/`: Arquivos `.html` com estrutura da interface web.
- `application.properties`: Configurações da aplicação.
