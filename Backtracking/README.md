# Backtracking - Tarefa EBAC

Este diretório contém a implementação de um algoritmo de **Backtracking** como parte das tarefas do curso de Java Backend da EBAC.

## Objetivo

Demonstrar o funcionamento da técnica de **Backtracking**, que é usada para resolver problemas de forma recursiva, explorando todas as possibilidades até encontrar uma solução válida.

## Conteúdo

- `Backtracking.java`: Classe principal que contém a lógica do algoritmo.
- Exemplos de uso e testes podem ser adicionados para ilustrar o funcionamento.
