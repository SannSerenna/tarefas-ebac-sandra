# Vendas - Módulo 30 🛒

Este diretório contém uma aplicação Java desenvolvida como parte do **Módulo 30** do curso de Java Backend da EBAC. O projeto simula um sistema de vendas, com foco em organização de dados, encapsulamento e boas práticas de programação orientada a objetos.

## Funcionalidades

- Cadastro de produtos com nome, preço e quantidade.
- Registro de vendas com cálculo de valor total.
- Exibição de informações detalhadas sobre produtos e vendas.

## Estrutura

- `Produto.java`: Classe que representa um produto com atributos e métodos relacionados.
- `Venda.java`: Classe que representa uma venda, contendo produtos e lógica de cálculo.
- `Main.java`: Classe principal que executa o sistema e demonstra seu funcionamento.
