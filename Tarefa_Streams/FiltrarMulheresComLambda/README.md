# Filtrar Mulheres com Lambda 👩‍💻

Este diretório contém uma aplicação Java que utiliza **Streams e expressões Lambda** para filtrar uma lista de pessoas, exibindo apenas aquelas do sexo feminino. O projeto foi desenvolvido como parte das atividades do curso de Java Backend da EBAC.

## Objetivo

- Praticar o uso de **Streams** e **Lambda expressions**.
- Filtrar dados de forma funcional e concisa.
- Demonstrar a manipulação de listas com base em critérios personalizados.

## Estrutura

- `Pessoa.java`: Classe que representa uma pessoa com atributos como nome, idade e sexo.
- `Main.java`: Classe principal que cria uma lista de pessoas e utiliza Stream + Lambda para filtrar mulheres.
