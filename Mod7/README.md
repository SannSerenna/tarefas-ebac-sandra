# Módulo 7 - Classes e Objetos 🧱

Este diretório contém os exercícios do **Módulo 7** do curso de Java Backend da EBAC. O foco está em aplicar os conceitos fundamentais de **classes, atributos, métodos e objetos**, pilares da programação orientada a objetos.

## Objetivo

- Criar classes Java com atributos e comportamentos.
- Instanciar objetos e manipular seus dados.
- Compreender o encapsulamento e a reutilização de código.

## Estrutura

- `Bicicleta.java`: Classe que representa uma bicicleta com atributos como modelo, cor e velocidade.
- `Main.java`: Classe principal que cria objetos da classe `Bicicleta` e demonstra seu funcionamento.
