# EBAC Services Demo 🚀

Este diretório contém uma demonstração de serviços Java, desenvolvida como parte das atividades do curso de Java Backend da EBAC. O projeto tem como objetivo aplicar conceitos de orientação a objetos, modularização e boas práticas de desenvolvimento.

## Funcionalidades

- Criação de serviços Java com métodos reutilizáveis.
- Demonstração de encapsulamento e organização de código.
- Simulação de chamadas de serviço em uma aplicação simples.

## Estrutura

- `Servico.java`: Classe que representa um serviço genérico com métodos de exemplo.
- `Main.java`: Classe principal que executa os serviços e exibe os resultados.
