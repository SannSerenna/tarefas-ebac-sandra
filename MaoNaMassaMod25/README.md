# Mão na Massa - Módulo 25 🧪

Este diretório contém os exercícios práticos do **Módulo 25** do curso de Java Backend da EBAC. O foco é aplicar os conceitos aprendidos sobre orientação a objetos, encapsulamento e modularização em uma atividade prática.

## Objetivo

- Consolidar os conhecimentos de Java aplicando-os em um projeto funcional.
- Criar classes com atributos e métodos bem definidos.
- Simular interações entre objetos e lógica de negócio.

## Estrutura

- `Cliente.java`: Classe que representa um cliente com seus dados.
- `Produto.java`: Classe que representa um produto com atributos como nome e preço.
- `Venda.java`: Classe que realiza operações de venda entre cliente e produto.
- `Main.java`: Classe principal que executa o sistema e demonstra seu funcionamento.
