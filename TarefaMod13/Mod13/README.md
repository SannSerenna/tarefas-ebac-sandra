# Módulo 13 - Orientação a Objetos 🧩

Este diretório contém os exercícios do **Módulo 13** do curso de Java Backend da EBAC. O foco está em aplicar os pilares da **programação orientada a objetos (POO)**, como encapsulamento, herança, abstração e polimorfismo.

## Objetivo

- Criar classes com atributos e métodos.
- Utilizar herança para reaproveitar código.
- Aplicar polimorfismo para flexibilizar comportamentos.
- Encapsular dados com modificadores de acesso.

## Estrutura

- `Pessoa.java`: Classe base com atributos comuns.
- `Cliente.java` e `Funcionario.java`: Classes que herdam de `Pessoa` e adicionam comportamentos específicos.
- `Main.java`: Classe principal que demonstra o uso das classes e seus relacionamentos.
