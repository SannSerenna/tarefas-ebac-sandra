# Padrões de Projeto - Parte 2 🧠

Este diretório contém uma aplicação Java desenvolvida como parte da segunda tarefa sobre **Padrões de Projeto** no curso de Java Backend da EBAC. O foco está em aplicar padrões adicionais como **Singleton**, **Strategy**, **Observer**, entre outros, para melhorar a organização e flexibilidade do código.

## Objetivo

- Demonstrar o uso de múltiplos padrões de projeto.
- Criar uma estrutura modular e extensível.
- Aplicar boas práticas de design orientado a objetos.

## Padrões Aplicados (exemplos possíveis)

- `Singleton`: Garante uma única instância de uma classe.
- `Strategy`: Permite trocar algoritmos em tempo de execução.
- `Observer`: Notifica objetos dependentes sobre mudanças de estado.
- `Builder`: Facilita a criação de objetos complexos.
- `Adapter`: Conecta interfaces incompatíveis.

## Estrutura

- `model/`: Classes que representam entidades do sistema.
- `strategy/`, `observer/`, `singleton/`: Pacotes com implementações específicas dos padrões.
- `Main.java`: Classe principal que demonstra o uso dos padrões.
