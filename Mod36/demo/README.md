# Módulo 36 - Demonstração de Spring Boot 🌱

Este diretório contém uma aplicação de demonstração desenvolvida no **Módulo 36** do curso de Java Backend da EBAC. O foco está em aplicar os conceitos de **Spring Boot**, incluindo criação de endpoints REST, configuração de projeto e boas práticas de desenvolvimento web.

## Funcionalidades

- Criação de uma API REST simples
- Mapeamento de rotas com `@RestController`
- Retorno de dados via JSON
- Testes básicos de requisições HTTP

## Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Maven
- Postman ou navegador para testes
