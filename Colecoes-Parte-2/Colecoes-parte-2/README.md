# Coleções - Parte 2 📚

Este diretório contém exercícios relacionados ao uso de **coleções em Java**, como parte do curso de Java Backend da EBAC. O foco está em praticar o uso de listas, conjuntos e mapas, além de aplicar conceitos como ordenação e manipulação de dados.

## Conteúdo

- `CadastroProduto.java`: Classe que representa um sistema de cadastro de produtos utilizando coleções.
- `Produto.java`: Classe que define os atributos e comportamentos de um produto.
- Outros arquivos podem incluir testes ou exemplos de uso.

## Conceitos Praticados

- Uso de `ArrayList`, `HashSet`, `TreeSet`, `HashMap`, entre outros.
- Ordenação de elementos com `Comparable` e `Comparator`.
- Iteração e manipulação de dados em coleções.
- Boas práticas de encapsulamento e organização de código.
