# Tarefa TDD - Test Driven Development ✅

Este diretório contém uma aplicação Java desenvolvida como parte das atividades do curso de Java Backend da EBAC, com foco na prática de **TDD (Desenvolvimento Orientado a Testes)**.

## Objetivo

- Aplicar os princípios do TDD na construção de uma aplicação.
- Escrever testes antes da implementação da lógica.
- Garantir que o código esteja sempre coberto por testes automatizados.

## Estrutura

- `Cliente.java`: Classe que representa a entidade cliente.
- `IClienteDAO.java`: Interface para operações de persistência.
- `ClienteDAO.java`: Implementação da interface com lógica de acesso a dados.
- `ClienteDAOTest.java`: Classe de testes unitários utilizando JUnit.

## Tecnologias Utilizadas

- Java 17+
- JUnit 5
- Maven (se aplicável)
